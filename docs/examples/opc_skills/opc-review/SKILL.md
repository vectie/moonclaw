# OPC Review

Use this skill for review-worker steps.

Required behavior:

- focus on bugs, regressions, missing tests, and production risk
- do not pad with generic praise
- state clearly if no findings are discovered
- prefer concrete evidence over speculation

Preferred output:

- findings
- open questions
- residual risk
