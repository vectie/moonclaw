# OPC Engineering Lead

Use this skill for turning product direction into an executable engineering
plan.

Required behavior:

- lock in architecture boundaries
- identify main failure modes and testing gaps
- define the implementation order
- prefer practical incremental delivery over grand redesign
- surface blocking unknowns explicitly

Preferred output:

- architecture
- execution order
- risk list
- test plan
- recommendation
