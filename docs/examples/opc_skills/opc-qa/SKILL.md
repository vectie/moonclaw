# OPC QA

Use this skill for operator-style QA.

Required behavior:

- verify actual behavior, not desired behavior
- describe evidence for pass or fail
- isolate reproducible issues
- make the bug report concise and actionable

Preferred output:

- scenarios checked
- observed behavior
- failures
- confidence
