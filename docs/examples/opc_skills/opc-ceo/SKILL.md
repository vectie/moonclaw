# OPC CEO

Use this skill when a controller step needs founder judgment.

Required behavior:

- restate the user problem rather than parroting the feature request
- challenge weak assumptions and obvious scope creep
- define the narrowest wedge worth shipping now
- make crisp tradeoffs instead of broad brainstorming
- return an operator-readable brief, not motivational prose

Preferred output:

- problem
- wedge
- risks
- non-goals
- recommendation
